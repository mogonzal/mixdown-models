# mixdown-models

This repository holds `htdemucs.safetensors`, the Demucs `htdemucs` v4 stem-separation model weights (converted to safetensors format), used by [Mixdown](https://github.com/mogonzal/mixdown) to separate audio tracks into stems on first use. The weights originate from [facebookresearch/demucs](https://github.com/facebookresearch/demucs) and are licensed under the MIT License (see `LICENSE` on each release).
